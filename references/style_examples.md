## 1. 钩子二创示范

核心原则：保灵魂保的是钩子力度和锁死项，不是那串具体的字。要像换个人把整段重新讲一遍，改动量 ≥30%。

### 正确示范

**原文**（稀缺独家 + 有缘人钩子）：
> 珍藏几十年的土方子，好多人挤破脑袋都想学，但我只交给刷到我的有缘人。

**✅ 合格洗法**（换句式、扩细节、力度更足）：
> 这个方子我自己压箱底珍藏了几十年，多少人托关系、想方设法都想跟我学，我谁也没轻易给，今天就单留给刷到我、跟我有缘的你。

**原文**（用户本人二创标杆，4.15）：
> 白眼球比较白的是正常的。

**✅ 重构后**：
> 眼白发黄的话，多半是肝胆在求救，你要是翻下眼皮一看，白得发青或者发黄，就得当心了。

### 反例（不合格）

**❌ 只换几个词**（照抄，无实质改动）：
> 珍藏好些年的老方子，许多人想学，我只给有缘人。

**❌ 力度泄了**（把稀缺钩子洗成普通分享）：
> 留了好些年的方子，分享给刷到我的你。

**❌ 书面化丢真人感**：
> 可能饮用不当 → 洗掉了「可能喝错了」的冲击力

## 2. 引导语替换与接缝处理

### 替换流程

1. `python scripts/pick_guidance.py --mode short|long|any` 取一条
2. 整段替换原文引导语段
3. 删残留账号自称（「我是XX医生」直接删）
4. 处理前后接缝——关联词配对、无半截句、过渡自然

### 接缝正确示范

**原文钩子段结尾** → **替换引导语** → **干货段开头**

> 【钩子尾】…今天就把这个压箱底的护肝方子告诉你。
> 【引导语，从库取】虽然我们素未谋面，但从现在开始，只要给我打个招呼，一朵小红花，从此身边就多一个中医朋友…
> 【干货开头】这个方子很简单，一共就三味药。

**✅ 接缝检查通过**：钩子尾「告诉你」自然引出引导语的「交朋友」→ 引导语尾「朋友」后，干货以「这个方子」承接，连贯。

### 接缝反例

**❌ 关联词悬空**：
> 虽然咱们素未谋面，你点个小红心就多了个朋友。
> → 缺「但」，应：虽然我们从未见过面，但你点个小红心…

**❌ 半截句**：
> …从此多了一个医生朋友。荷叶10克、陈皮6克…
> → 缺过渡，应插入「记住了，这个方子很简单——」之类

**❌ 造伪因果**（4.4 红线）：
> 点个小红心，是为了你家孩子能长高。
> → 荒谬，直接删。点赞和疗效不准绑因果。

## 3. 8 类灵魂保留 vs 软化对照

| 类别 | 保留（不改） | 过度软化（错的） |
|------|-------------|-----------------|
| 稀缺独家钩子 | 「珍藏几十年」「挤破脑袋都想学」 | 「留了好些年」「挺多人想知道」 |
| 精确数字 | 「3块钱」「95%」「九成」 | 「几块钱」「很多」「大部分」 |
| 强断言/反差 | 「枸杞水别喝，力量太弱」 | 「枸杞水可能不太够」 |
| 真人冲击句 | 「可能喝错了」 | 「可能饮用方法不当」 |
| 情感共情 | 「把你当家人」「从不藏私」 | 删掉情感句 |
| 紧迫召唤 | 「赶紧收藏」「一定仔细看完」 | 「可以收藏一下」「建议看看」 |
| 身份背书 | 「行医30年」「祖传」 | 「从医多年」「家里传的」 |
| 标志排比/口诀 | 「血虚掉头发，肝虚眼睛干…」 | 拆散重组、破坏节奏 |

### 特别说明

- **情感/服务承诺**（A.5）≠ 疗效承诺，前者保留、后者软化
- 例：「我从不藏私」→ 保留（情感承诺）
- 例：「100%治好」→ 软化为「能帮助改善」（疗效打包票）
- **排比/口诀型**只纠错字+顺人称，不重组，判断标准：原文已顺、已口语就不大改

## 4. 逻辑断裂四类排查（4.3）

### 4.1 关联词配对

**❌ 错误**：虽然咱们素未谋面，你点个小红心就多了个朋友。
**✅ 修正**：虽然我们从未见过面，但你点个小红心、加个关注，从此就会多一个靠谱的医生朋友。

**规则**：「虽然」必有「但」、「只要」必有「就」、「不但」必有「而且」——不开头不收尾、不悬空。

### 4.2 论断有铺垫

**❌ 错误**：我从不藏私。
**✅ 修正**：但熟悉我的朋友都知道，我从不藏私。

**规则**：自夸/结论前要有由头，不能凭空来。

### 4.3 因果说圆

**❌ 错误**：这两点连起来是三焦经，所以推按就能疏通三焦。
**✅ 修正**：这两点正好是手少阳三焦经的循行路线，在上面来回推按，就能帮助疏通三焦的气机。

**规则**：原因和结果之间逻辑要接得上、说实，不跳跃。

### 4.4 无半截句、无跳跃

**❌ 错误**：…从此多了个医生朋友。枸杞10克菊花6克。
**✅ 修正**：…从此多了个医生朋友。今天这个方子你得记好：枸杞10克，菊花6克。

**规则**：每句主谓完整，相邻句衔接得上，不能从互动突然跳到药名。

## 5. 4.4 精修清单对照

| 规则 | ❌ 错误 | ✅ 正确 |
|------|--------|--------|
| 功效不说死 | 「能祛风除湿」「能肝肾同补」 | 「能帮助祛风除湿」「能帮助肝肾同补」 |
| 夸张稀缺降档 | 「几个亿都买不到」「有钱都买不到」 | 「几个亿都难买到」「有钱都难买到」 |
| 不弱化就医 | 「小毛病自己就能调」 | 删除，不教唆自疗 |
| 接缝不造伪因果 | 「点个小爱心，是为了你家孩子能长高」 | 直接删掉伪因果句 |
| 用词精准 | 「不管你是脂肪肝还是…」「可能就喝错了」 | 「如果你有脂肪肝或者…」「可能喝错了」 |
| 就医提醒精炼 | 「是需要正规治疗的，才稳妥，你都记住了…」 | 「带状疱疹72小时内需口服抗病毒药，外敷只是辅助。」（不堆叠冗词） |
| 量词精确 | 「一味仙人掌」 | 「这个仙人掌」（一味只接中药材） |
| 辨证兜底格式 | （需辨证为肝肾阴虚尤其适合腰膝酸软…） | （需辨证为肝肾阴虚）平时腰膝酸软、头晕耳鸣的朋友可以试试。 |

## 6. 大白话用词替换表

受众中老年，用词一律往大白话走：

| 原词 | 替换 |
|------|------|
| 滋养 | 养好 |
| 预警 | 提个醒 |
| 提示肺部隐患 | 说明肺上可能有毛病 |
| 受损严重 | 坏得厉害 |
| 别无他求 | 不图别的 |
| 人体自带 | 咱们身上自带 |
| 操作 | 做起来 |
| 微微发热 | 有点发热 |
| 辨证 | 辨证（术语不改） |
| 证型名 | 不改 |
| 药材名+克数 | 不改 |

**衔接词白名单**（只用医生向）：但 / 其实 / 所以 / 在中医看来 / 这样一来 / 说到底 / 这里提醒你 / 记住
**禁用**：「话说回来」「有意思的是」——闲聊抖包袱腔，掉专业度。
