## 1. 钩子二创示范

核心原则：保灵魂保的是钩子力度和锁死项，不是那串具体的字。要像换个人把整段重新讲一遍，改动量 ≥30%。

### 正确示范

**原文**（稀缺独家 + 有缘人钩子）：
> 珍藏几十年的土方子，好多人挤破脑袋都想学，但我只交给刷到我的有缘人。

**✅ 合格洗法**（换句式、扩细节、力度更足）：
> 这个方子我自己压箱底珍藏了几十年，多少人托关系、想方设法都想跟我学，我谁也没轻易给，今天就单留给刷到我、跟我有缘的你。

**原文**（用户本人二创标杆，4.15）：
> 白眼球比较白的是正常的。

**✅ 重构后**：
> 眼白发黄的话，多半是肝胆在求救，你要是翻下眼皮一看，白得发青或者发黄，就得当心了。

### 反例（不合格）

**❌ 只换几个词**（照抄，无实质改动）：
> 珍藏好些年的老方子，许多人想学，我只给有缘人。

**❌ 力度泄了**（把稀缺钩子洗成普通分享）：
> 留了好些年的方子，分享给刷到我的你。

**❌ 书面化丢真人感**：
> 可能饮用不当 → 洗掉了「可能喝错了」的冲击力

## 2. 引导语替换与接缝处理

**替换流程（正式参数以 `SKILL.md` 为准）**

1. 用 `pick_guidance.py` 一次取多条已审核候选
2. 整段替换原文引导语段
3. 删残留账号自称（「我是XX医生」直接删）
4. 处理前后接缝——关联词配对、无半截句、过渡自然

**特别说明**：`【】` 和冒号只用于示例标注，不得复制进正式正文。

**原文钩子段结尾** → **替换引导语** → **干货段开头**

> 【钩子尾】…今天就把这个压箱底的护肝方子告诉你。
> 【引导语，从库取】虽然我们素未谋面，但从现在开始，只要给我打个招呼，一朵小红花，从此身边就多一个中医朋友…
> 【干货开头】这个方子很简单，一共就三味药。

**✅ 接缝检查通过**：钩子尾「告诉你」自然引出引导语的「交朋友」→ 引导语尾「朋友」后，干货以「这个方子」承接，连贯。

### 接缝反例

**❌ 关联词悬空**：
> 虽然咱们素未谋面，你点个小红心就多了个朋友。
> → 缺「但」，应：虽然我们从未见过面，但你点个小红心…

**❌ 半截句**：
> …从此多了一个医生朋友。荷叶10克、陈皮6克…
> → 缺过渡，应插入「记住了，这个方子很简单，接下来把药材说清楚」一类短桥

**❌ 造伪因果**（4.4 红线）：
> 点个小红心，是为了你家孩子能长高。
> → 荒谬，直接删。点赞和疗效不准绑因果。

## 3. 8 类灵魂保留 vs 软化对照

| 类别 | 保留（不改） | 过度软化（错的） |
|------|-------------|-----------------|
| 稀缺独家钩子 | 「珍藏几十年」「挤破脑袋都想学」的力度 | 「留了好些年」「挺多人想知道」 |
| 精确数字 | 「3块钱」「95%」「九成」 | 「几块钱」「很多」「大部分」 |
| 强断言/反差 | 「枸杞水别喝，力量太弱」 | 「枸杞水可能不太够」 |
| 真人冲击句 | 「可能喝错了」 | 「可能饮用方法不当」 |
| 情感共情 | 「把你当家人」「从不藏私」 | 删掉情感句 |
| 紧迫召唤 | 「赶紧收藏」「一定仔细看完」 | 「可以收藏一下」「建议看看」 |
| 身份背书 | 「行医30年」「祖传」的事实与权威力度 | 「从医多年」「家里传的」 |
| 标志排比/口诀 | 「血虚掉头发，肝虚眼睛干…」 | 拆散重组、破坏节奏 |

### 特别说明

- **情感/服务承诺**（A.5）≠ 疗效承诺，前者保留、后者软化
- 例：「我从不藏私」→ 保留（情感承诺）
- 例：「100%治好」→ 软化为「能帮助改善」（疗效打包票）
- **排比/口诀型**只纠错字+顺人称，不重组，判断标准：原文已顺、已口语就不大改

## 4. 逻辑断裂四类排查（4.3）

### 4.1 关联词配对

**❌ 错误**：虽然咱们素未谋面，你点个小红心就多了个朋友。
**✅ 修正**：虽然我们从未见过面，但你点个小红心、加个关注，从此就会多一个靠谱的医生朋友。

**规则**：「虽然」必有「但」、「只要」必有「就」、「不但」必有「而且」——不开头不收尾、不悬空。

### 4.2 论断有铺垫

**❌ 错误**：我从不藏私。
**✅ 修正**：但熟悉我的朋友都知道，我从不藏私。

**规则**：自夸/结论前要有由头，不能凭空来。

### 4.3 因果说圆

**❌ 错误**：这两点连起来是三焦经，所以推按就能疏通三焦。
**✅ 修正**：这两点正好是手少阳三焦经的循行路线，在上面来回推按，就能帮助疏通三焦的气机。

**规则**：原因和结果之间逻辑要接得上、说实，不跳跃。

### 4.4 无半截句、无跳跃

**❌ 错误**：…从此多了个医生朋友。枸杞10克菊花6克。
**✅ 修正**：…从此多了个医生朋友。今天这个方子你得记好，枸杞10克，菊花6克。

**规则**：每句主谓完整，相邻句衔接得上，不能从互动突然跳到药名。

## 5. 4.4 精修清单对照

| 规则 | ❌ 错误 | ✅ 正确 |
|------|--------|--------|
| 功效不说死 | 「能祛风除湿」「能肝肾同补」 | 「能帮助祛风除湿」「能帮助肝肾同补」 |
| 夸张稀缺降档 | 「几个亿都买不到」「有钱都买不到」 | 「几个亿都难买到」「有钱都难买到」（仅适用于非引导语段，引导语段已整段从库替换） |
| 不弱化就医 | 「小毛病自己就能调」 | 删除，不教唆自疗 |
| 接缝不造伪因果 | 「点个小爱心，是为了你家孩子能长高」 | 直接删掉伪因果句 |
| 用词精准 | 「不管你是脂肪肝还是…」「可能就喝错了」 | 「如果你有脂肪肝或者…」「可能喝错了」 |
| 就医提醒精炼 | 「是需要正规治疗的，才稳妥，你都记住了…」 | 「带状疱疹72小时内需口服抗病毒药，外敷只是辅助。」（不堆叠冗词） |
| 量词精确 | 「一味仙人掌」 | 「这个仙人掌」（一味只接中药材） |
| 辨证兜底格式 | （需辨证为肝肾阴虚尤其适合腰膝酸软…） | （需辨证为肝肾阴虚）平时腰膝酸软、头晕耳鸣的朋友可以试试。 |

## 6. 大白话用词替换表

受众中老年，用词一律往大白话走：

| 原词 | 替换 |
|------|------|
| 滋养 | 养好 |
| 预警 | 提个醒 |
| 提示肺部隐患 | 说明肺上可能有毛病 |
| 受损严重 | 坏得厉害 |
| 别无他求 | 不图别的 |
| 人体自带 | 咱们身上自带 |
| 操作 | 做起来 |
| 微微发热 | 有点发热 |
| 辨证 | 辨证（术语不改） |
| 证型名 | 不改 |
| 药材名+克数 | 不改 |

**衔接词白名单**（只用医生向）：但 / 其实 / 所以 / 在中医看来 / 这样一来 / 说到底 / 这里提醒你 / 记住
**禁用**：「话说回来」「有意思的是」——闲聊抖包袱腔，掉专业度。

## 7. 引导语主题匹配（4.1 新增）

### 正例（通用交朋友，任何主题都搭）

> 虽然我们素未谋面，但从现在开始，只要给我打个招呼，一朵小红花，从此身边就多一个中医朋友…

→ 适用于任何健康主题，因为"交个医生朋友"是通用价值承诺。

### 反例（主题不匹配）

> 帮你省钱，少遭罪。

→ 放在"孩子长高"主题里不搭——"省钱少遭罪"与"孩子长高"无因果逻辑关联。应换一条通用型引导语。

## 8. 接缝语义重复（4.1 新增）

### 反例

> …特别管用。这个调理方法简单又好用…

→ "管用"和"好用"同义重复，引导语首句跟前段末句撞车。处理：删引导语首句重复部分。

### 正确处理

> …特别管用。很多人当成传家宝轻易不外传，我免费分享出来…

→ 引导语直接从下一句开始，跳过语义重复的首句。

## 9. 收尾命令式 vs 建议式（4.4 新增）

### ❌ 命令式（不可用）

> 记不住先收藏，回去照着做就行。
> 记不住就收藏好，回去煮上喝。
> 记不住就收藏起来，回去照着煮。

### ✅ 建议式

> 记不住先收藏，有时间慢慢看。
> 记不住就收藏，用的时候翻出来看。
> 记不住就收藏起来，回去慢慢看。

## 10. 程度副词升级反例（4.2 新增）

### ❌ 力度升级（不可用）

> 原文"相当管用" → 洗成"特别管用"

→ "相当"换"特别"是升级程度副词。"力度只增不减"只适用于 8 类灵魂钩子，不适用于普通描述词。

### ✅ 保持同力度

> 原文「相当实用」若换成「特别实用」同样属于错误升级。
> 应保持「相当」不动，或换成同级别的「挺实用」。

## 11. 口播正文与专业注解分层

### ❌ 反例：把洗稿改成辟谣和临床说明

> 更不要一上来就认定必须手术。到底怎么处理，不能只盯着某个结石尺寸，还要让医生结合位置和症状来判断。
>
> 如果出现这些表现，先把原因和证型辨清，再看这个思路适不适合。

→ 前一段在逐条纠正原文，后一段是抽象审稿腔；听感像临床说明，不像医生口播二创。鉴别诊断、完整适用/禁忌人群、常规治疗或复查提醒应放 `notes/tips`，正文只留钩子、必要解释、引导语、干货和简单收尾。

### ✅ 正确处理：正文直接讲，专业信息下沉

> 体检查出胆结石，先别慌。今天把这个排石方给你讲清楚。

→ 直接接住观众和主题，不在正文展开手术阈值或鉴别诊断。需要补充的专业边界放在 Word 后三段。

### 引导语位置与接缝

- 原文引导语在开头钩子之后，就在同一功能位置整段替换，不能因为套固定叙事链而挪到中医解释或症状之后。
- 放对位置还不够，前句要自然引出这段分享，后句要自然回到中医解释或方子；前后任一处断层都要补桥。

### 方子开头要像真人说话

**❌ 机械命令**：
> 记好海金沙9克、金钱草15克、鸡内金9克。

**✅ 自然口播**：
> 可以取海金沙9克、金钱草15克、鸡内金9克。

→ 「记好」不是固定模板。根据上下文选「可以取」「准备」「这个方子用」；只有前文确实形成提醒或紧迫语气时才用「记好」。

## 12. 语义微调与可信口播

### 12.1 情绪安抚保方向，也要符合惯用搭配

**❌ 近义成分硬叠**：
> 查出问题，先别急着慌。

**✅ 自然口播**：
> 查出问题，先别慌。
>
> 先不用过度害怕，今天把这个思路给你讲清楚。

→ 「先别慌」本身可以用；问题是为了二创把「急」和「慌」硬叠。安抚的是当下情绪，不等于替病情下「没事」「肯定不用治疗」的结论。

### 12.2 指示语有锚点，直接祈使用基本式

**❌ 指代悬空、体貌不顺**：
> 今天这个方法你记好了。
>
> 下面这个穴位你收好了。

**✅ 交代本次要讲什么**：
> 今天讲的这个方法你记好。
>
> 下面要说的这个穴位你收好。

**✅ 合法完成体**：
> 你要是已经记好了步骤，再往下做。

→ 「记好了」不是全局禁词；直接提醒用「记好」，陈述动作已经完成时才用「记好了」。

### 12.3 强利益钩子保留，不把不可控结果写成保证

**❌ 替观众保证结果**：
> 不让你多花一分冤枉钱。
>
> 保证你以后不用跑医院。

**✅ 改成帮助或可能性，利益点不丢**：
> 能让你少花冤枉钱。
>
> 希望这些知识能帮你少走弯路。

**✅ 可控的内容服务承诺**：
> 我会继续分享实用的健康知识。

→ 稀缺、有缘人、收藏等强流量话术照常保留，只修创作者控制不了的结果保证。

### 12.4 医学归因留范围，术语紧邻白话解释

**❌ 单因、必然式归因**：
> 这个病的根子就是湿热。
>
> 这些症状全都是气血不足引起的。

**✅ 按论断范围留余地**：
> 在中医看来，这类情况常和湿热有关。
>
> 这类表现多见于气血不足。

**✅ 术语保真，再补一句解释**：
> 中医说的湿热，可以简单理解为湿气和热气缠在一起。

→ 不是把每个术语换成俗话，而是保留准确术语，再用中老年人听得懂的一句话解释。

### 12.5 引导语前先把价值判断落到当前主题上

**❌ 位置正确，但价值判断没有主语**：
> ……这类情况常和湿热有关。90%的人都不知道这个实用的小知识，好多人挤破脑袋都想学。

**✅ 当前主题回指 → 价值判断**：
> ……这类情况常和湿热有关。今天跟大家分享的这个，是针对这类问题的实用方法。90%的人都不知道，好多人挤破脑袋都想学。

**✅ 不套固定桥的变体**：
> ……这类情况常和湿热有关。这个方法就是接下来要讲的重点，很多人还不知道。

→ 桥句必须回指上文的疾病、方子、穴位或方法；不要求每篇都机械使用「今天跟大家分享的这个」。
