# 洗稿风格示例库

> 本文件只解释已在 `references/rewrite_playbook.md` 定义的写法，不创设规则，不提供医学事实。若示例与权威规范或机器校验冲突，以权威规范为准。

## 1. 钩子重讲

原文：
> 这个方法很多人都想学，我只分享给刷到我的有缘人。

合格重讲：
> 好多人到处打听这个方法，却没人愿意一次讲清楚。既然你刷到了，我就把关键步骤说明白。

为什么自然：保留稀缺和有缘人功能，但句式和叙事顺序已经变化。身份、资历、患者经历和效果数字只有原稿明确出现并通过解析审批时才能保留。

## 2. 引导语选择与接缝

前文：
> 这类情况在生活中并不少见，很多人却一直没找到合适的办法。

候选：
> 这个方法很多人花钱都不一定能学到，我愿意免费分享给刷到的你。觉得实用，帮忙点个红心，就是最大的支持。

后文：
> 大家可以取已经核对过的药材和剂量，按原稿做法使用。

为什么自然：前文先交代当前问题，候选承接“这个方法”的价值，后文立即兑现做法，没有重复预告。若候选与主题不搭，可在首次候选集内改选一次；都不合适时直接用短承接。

## 3. 病机后直接落做法

不自然：
> 在中医看来，这类表现可能和某种病机有关。顺着这个思路，临床上常会用到下面这味药。

自然：
> 在中医看来，这类表现可能和某种病机有关。大家可以取已经批准的药材和剂量，按原稿方式使用。

为什么自然：医生直接对观众说做法，不切换成第三方科普解说。这里的药材、剂量和证型只是结构占位，正式稿必须来自解析锁定项。

## 4. 实际节点逐边检查

合法结构可以是：

- 钩子 → 引导语 → 病机 → 方子 → 收尾
- 钩子 → 痛点 → 方子 → 收尾
- 钩子 → 病机 → 穴位 → 收尾

可选节点缺席不算断链。判断标准是每个实际相邻节点是否回答了前一句留下的问题，而不是是否凑齐固定六段。

## 5. 动宾与时间词听感

不自然：
> 今天再把这个土方法讲透。今天要说的方法很简单。今天跟大家分享这招。

自然：
> 这个土方法我再说一次，记住了，能帮你少走弯路。

为什么自然：只预告一次，下一句就进入内容；“把土方法讲透”改为常见口语搭配。

## 6. 医学边界与字段分区

正文只保留钩子、必要解释、做法和简单收尾。以下内容默认放到对应字段：

- 鉴别诊断、症状可能有多种原因 → `notes`
- 适用人群、禁忌、使用和就医提醒 → `tips`
- 采摘、炮制和储存 → `processing`

正文不要连续解释为什么不能把话说满，也不要写成审稿说明。

## 7. 收尾

合格收尾：
> 记不住先收藏，用的时候再翻出来看。

> 这个方法，你记住了吗？

收尾只帮助观众记住内容或做简单互动；具体使用信息应在方子节点说清，不要在结尾追加新的治疗指令。
