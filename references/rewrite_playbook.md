# 洗稿手册（rewrite_playbook）

> **本文件是医誉康达口播洗稿规则的唯一事实源。** SKILL.md 和 prompts/ 不得复述这些规则，只可引用本文件。修改洗稿规则只改这里一处。
>
> 洗稿不是换词躲查重。核心是：**先把文案拆成功能段、搭出叙事骨架，再顺着骨架从头到尾重讲一遍，边写边缝**。把下面的流程做到位，二创 + 逻辑通顺自然就和原稿拉开距离；为躲查重生硬换词反而损口播流畅度，本末倒置。成稿的口播流畅度、完整度不低于原稿。

---

## 一、洗稿流程（先搭骨架，再顺链重讲）

组装式写作（各段独立洗好再拼）天然会产生逻辑断层、生硬接缝、伪因果。所以不各段独立写，而是**先搭骨架让断层在动笔前暴露，再顺叙事顺序逐节点重讲、边写边缝合**。按 Step 1→4 顺序做，Step 4 是必过的收尾关卡。

### Step 1　拆段 + 定位引导语

把文案按功能拆开，认出这 6 类功能段：

1. **开头钩子段**：黄金 3S，框人群 + 埋钩子（痛点前置／热点季节契合／常见物切入／信息差认知升维「你不知道的好东西」／反差／「少往医院跑」类心智钩子）。
2. **引导语段（绝大多数有，赛道命根）**：稀缺性（挤破脑袋都想学／有钱买不到／不传之秘）+ 有缘人话术（只交给刷到我的有缘人）+ 利益承诺（多个医生朋友、答疑解惑）+ 统一阵营（不赚钱、动了商业利益、药店干不下去）+ 无私奉献人设 + 真心话拉近距离 + 互动引导（小红花／加号关注／收藏／评论）——这一整块。位置通常在钩子段之后、干货之前。
3. **中医解释段（可选）**：用中医理论（不通则痛、精血同源、肝经湿热）解释病因，建可信度、引出方子。
4. **痛点／人群段（可选）**：罗列典型症状（迎风流泪、视物模糊、腰膝酸软…）让观众对号入座。
5. **方子段（核心干货）**：药材 + 克数 + 功效。
6. **功效收尾段**：说功效（避免承诺疗效）+ 结尾简单互动。

**位置锁定（必做）**：拆出引导语段后，标注它在原文中的位置。Step 3 落地引导语时必须在原位置、不移动段落顺序：

- 在钩子段之后、痛点/症状之前？
- 在痛点/症状之后、方子之前？
- 穿插在某段中间？
- ⚠️ **原文无引导语段：不是「可跳过」，而是必须从引导语库取一条插入**。默认插入位置：痛点/人群段之后、方子/干货段之前（不是钩子之后）。原文没有引导语 ≠ 不需要引导语——引导语是赛道命根。

**同时选好引导语（供 Step 3 落地）**：运行 `python scripts/pick_guidance.py --mode <short|long|any> --count 3` 取 3 条候选，一次挑定，不回抽：

- **选档**：原文 ≥200 字 → `--mode short`（≤75 字，给干货留空间）；原文 <200 字 → `--mode long`（≥95 字，充实整体）；不确定 → 省略 `--mode`（any）。
- **从 3 条候选里挑主题最贴文章的一条**。多数引导语是通用型（交医生朋友／有缘人／答疑解惑），任何健康主题都搭，直接选通用型即可。只有当候选里出现**绑定具体利益**（如「帮你省钱少遭罪」）且与本文主题无因果关联时才排除它。**一次决策选定，不替换后再回头重取。**
- 注：某档命中不足时脚本会向相邻长度就近补足，75/95 是理想阈值。

### Step 2　搭叙事链骨架（先不写字，先挂节点）

动笔前，先把各段挂到读者问答链的节点上，把全文当一个故事走一遍——追问每个节点「读者此时心里会问什么，下一句回答了吗」：

```
钩子（承诺）    → 读者问：什么东西？→ 揭秘/解释段须回答
揭秘/解释段     → 读者问：跟我有什么关系？→ 痛点段须回答
痛点段          → 读者问：那怎么办？→ 桥 + 引导语须回答（桥上接痛点、下接引导语的承诺）
引导语          → 读者问：说了半天，方子呢？→ 方子段须回答
方子 + 辨证     → 读者问：怎么记/怎么用？→ 收尾须回答
```

**此刻就标记缺口**：哪个节点原文缺（无引导语段→标「需插引导语 + 补桥」；无痛点段→标「揭秘直接接引导语，需补一句由头」），断层在动笔前就暴露、就地规划怎么补，**不留到成稿后再查**。桥的写法不固定——用前段的痛点/场景做由头，引到引导语/下一段的价值主张，只要每步问答接上，桥自然长出来。

### Step 3　顺链逐节点重讲（从头写到尾，边写边缝）

**按叙事顺序**从钩子写到收尾，每写一个节点，显式回答上一个节点给读者留下的问题——接缝不是事后补的补丁，而是「写下一段时本来就要接住上一段的问题」。逐节点套用下方 **A–F 写作指令**。写到引导语节点时，把 Step 1 选定的引导语**当场**落地、即时缝合前后（删账号自称、处理语义重复、加桥），不要「各段写完再回头补两处接缝」。

### Step 4　一次通读（必过的收尾关卡）

从头读一遍，只做机器测不了的判断（能正则的项由 `validate_output.py` 兜底，不在这里靠肉眼）：

- **叙事链每步问答接上没**：钩子→揭秘→痛点→桥+引导语→方子→收尾，任一节点跳过（如痛点段直接跳到引导语的「不用跑医院」，中间缺了「我有解法→所以不用跑」）就是断层，回 Step 3 补。**尤其引导语落地的两处接缝**。
- **8 类灵魂钩子力度只增不减**：没被软化、泄气、模糊。
- **二创改动量 ≥30%**：非逐句对译，无连续 10 字以上照抄。
- **关联词配对**：「虽然」必有「但」、「只要」必有「就」、「不但」必有「而且」，不悬空。例错「虽然咱们素未谋面，你点个小红心就多了个朋友」→ 应「虽然我们从未见过面，但你点个小红心、加个关注，从此就多一个靠谱的医生朋友」。
- **论断有铺垫**：自夸/结论前有由头。例错「我从不藏私」→ 应「但熟悉我的朋友都知道，我从不藏私」。
- **因果说圆、无半截句、无跳跃**：每句主谓完整，相邻句衔接得上。

然后跑机器校验（见第四节）。

## 二、A–F 写作指令（Step 3 逐节点套用）

### A. 8 类引流灵魂：力度只增不减，用自己的话重讲，绝不软化/泄气/模糊

重讲时把钩子讲得更勾人（怎么重讲见 F）；其中锁死项（精确数字/克数/证型/病症名/标题）连字都不动。

1. **稀缺/独家钩子**：「珍藏几十年」「挤破脑袋都想学」「到处打听都求不来」
2. **精确数字**：「3块钱」「95%」「九成」「一分钱都不要多花」「成本不到两块钱」——精确数字本身就是钩子，绝不模糊成「几块钱」「很多」
3. **斩钉截铁的强断言/反差**：「枸杞水别喝、生蚝腰子别再吃了，力量太弱」
4. **脱口而出有冲击力的真人句**：如「可能喝错了」，不重写成书面顺溜版（书面化 = 丢真人感）
5. **情感共情钩子**：「我从不藏私」「熟悉我的朋友都知道」「把你当家人」「刷到就是缘分」（服务/情感承诺 ≠ 疗效承诺，保留）
6. **紧迫/行动召唤**：「赶紧收藏」「这一条一定要仔细看完」
7. **身份/权威背书**：「行医X年」「祖传」「生长发育专家」
8. **标志口头禅/节奏排比**：IP 标志开场、口诀、排比——只纠错字 + 顺人称，不重组（强行二创破坏节奏）

### B. 只对这 3 类下手（软化/删的全部范围，此外一律不动）

- **① 医疗误导高风险**（健康安全考量，非话术）：把普通体征/症状强行关联癌症重病、可能耽误就医的内容删除；删完若开头报了数量（如「3个变化」）同步改成剩下的实际数量。涉及需及时正规治疗的急重病（如带状疱疹/蛇缠腰），把就医提示（如「72小时内口服抗病毒药」）拎成独立结尾、点明土方只是辅助，不让土方盖过正规治疗。
- **② 攻击同行**：「卖高价暴利产品要记恨我」这类删或改中性。
- **③ 正文里绝对化疗效打包票**：「根治」「断根」「越喝越好」「100%治好」这类把疗效说死的，软化成留有余地的说法。⚠️ 仅限正文；区分情感/服务承诺（属 A.5 灵魂，保留），别误伤。
- 除以上三类，稀缺感、独家钩子、精确数字、斩钉截铁的断言、情感钩子、紧迫召唤、身份背书全部原样保留——那是灵魂不是违规。

### C. 标题党不动（重要）

标题是流量命根，「癌」「告诉你」「越喝肝越好」这类悬念和钩子原样保留、绝不软化（别改成「别大意」这种没人点的）。参考：用户本人成稿标题「体内有没有癌，看看双手就知道」一字未动。

### D. 加辨证兜底

方剂/功效讲完后，紧跟圆括号（需辨证为XX）——**括号里只放证型这一项**；可感知的典型症状**另起一句、放在括号外面**，用「…可以试试」这类留余地的说法收尾，别塞进括号里、也别用「尤其适合」这种打包票口气。

例：「…能帮助补肝益肾、养血活血（需辨证为肝肾阴虚）平时腰膝酸软、头晕耳鸣、手脚心发热的朋友可以试试」。

⚠️ 用圆括号（）不用方括号【】（【】是 docx 后三段专用，正文出现即违规）；括号紧跟功效、不夹句中；症状外置不入括号。

### E. 纠错字 + 用词准确

- 修语音转写硬伤：「保障搭配」→「宝藏搭配」、「柱状指」→「杵状指」、「辣潦草」→「辣蓼草」、「辩证」→「辨证」、「随眠」→「睡眠」、「又多重」→「有多重」；必要时把术语补准（「竖纹」→「黑色竖纹」）。术语拿不准先按解析核对再改，不凭感觉。
- **量词精准**：「一味」后面只接中药材，非药材（仙人掌等）改「这个」。
- **并列罗列症状**用「如果你有……或者……」，别用「不管你是……还是……」。
- **删赘字**：「可能就喝错了」→「可能喝错了」。

### F. 二创重组（默认手法、质量核心，整体改动量不低于 30%）

- **「保灵魂」保的是钩子的力度和锁死项，不是那串具体的字**——稀缺/情感/紧迫/身份这些钩子要用自己的话重新讲一遍（换说法、力度只增不减），同时精确数字/克数/药材名/证型/病症名/标题锁死不动。两头都别走：过度软化把灵魂洗没、只换几个词的照抄，都不合格。
- **像换个人把整段重新讲一遍**：换句式、换说法、调结构、补过渡、扩写细节和病感描写。参考用户本人二创（「白眼球比较白的是正常的」→「眼白发黄的话，多半是肝胆在求救…」）。
- **改动量操作定义**：每句话至少换一种句式或说法，整段至少 1/3 的句子结构发生明显变化（主谓宾顺序调整、长句拆短、短句合并、因果倒置）。打散原文句子顺序后重组，不逐句对译。
- **照抄禁令**：除药材名、克数、证型、病症名、标题外，禁止连续 10 字以上与原文相同的短语。
- **钩子二创示范（力度只增不减）**：原「珍藏几十年的土方子，好多人挤破脑袋都想学，但我只交给刷到我的有缘人」→ ✅「这个方子我自己压箱底珍藏了几十年，多少人托关系、想方设法都想跟我学，我谁也没轻易给，今天就单留给刷到我、跟我有缘的你」（换句式、扩细节、改动过半，稀缺独家 + 有缘人钩子力度更足）。⚠️ 反例：「留了好些年的方子，分享给刷到我的你」——力度泄了。
- **打散重组示范**：原「今天给大家分享一个老祖宗传下来的小方子，专门针对晚上睡不好、翻来覆去睡不着的情况」→ ❌ 照抄式「今天和大家说一个祖宗传下来的小方，针对夜里睡不好翻来覆去的问题」→ ✅ 打散重组「晚上翻来覆去睡不着，心里烦得很？这个法子是祖辈传下来的，专门调理睡不安稳」。
- **锁死项连字都不动**：精确数字（95%/3块钱/九成/72小时）、方剂药材名与克数、证型、病症名、标题、经核对的医学事实——原样，但承载它们的句子照样重讲。例：「取酸枣仁15克，百合10克，莲子10克，加水煮20分钟」→ ✅「准备酸枣仁15克、百合10克、莲子10克，水开后煮20分钟」（克数不动，说法换）。
- **用词一律往大白话走**（受众中老年）：滋养→养好、预警→提个醒、提示肺部隐患→说明肺上可能有毛病、受损严重→坏得厉害、别无他求→不图别的、人体自带→咱们身上自带、操作→做起来、微微发热→有点发热。详见 `style_examples.md` 第 6 节替换表。
- **衔接/过渡只用医生向逻辑词**：但／其实／所以／在中医看来／这样一来／说到底／这里提醒你／记住。⚠️ 禁用「话说回来」「有意思的是」这类闲聊抖包袱腔（掉专业度、模板化、伪原创味）。
- **人称全程统一用「你」**（这个 IP 一贯用「你」），不与「您」「你们」混用；钩子互动稳重可信（医生 IP 不像带货：不强行因果、不矫情、不用捡漏占便宜口气）。
- **功效不说死**：方子功效动词由「能 X」改成「能帮助 X／有助于 X」（「能祛风除湿」→「能帮助祛风除湿」「能肝肾同补」→「能帮助肝肾同补」）；介绍药材客观属性（「这味药能……」）不受此限。
- **夸张稀缺词降一档**（仅非引导语段）：「买不到」→「难买到」（「几个亿都买不到」→「几个亿都难买到」）——稀缺钩子保留，但不把话说绝对。引导语段已整段从库替换，此规则不适用于引导语段。
- **条件不绝对**：用「如果」代替「只要」做条件句引导，除非原句「只要…就…」是完整的关联词对。反例：「只要你睡着了突然抽一下」→「如果你睡着了突然抽一下」。
- **无市井口气**：医生 IP 要稳重。「今天这招你算赶上了」→「恭喜你刷到这条视频」。避免「这招你赚了／你算赶上了／捡到宝了」这类捡漏占便宜口气。
- **普通描述词不得升级程度**：原文的程度副词（相当/比较/有点/挺）保持同力度，不升级（相当→特别、比较→非常 都不行）。「力度只增不减」仅适用于 A 节 8 类灵魂钩子，不适用于普通描述词。
- **不添加原文没有的地理/场景细节**：除非能确认合理（如「河边辣蓼草」常见），否则不自行添加「路边/山上/田间」等场景词。反例：仙人掌加「路边」→ 中国路边不常见仙人掌，删「路边」。

### 引导语节点专项写法（Step 3 落地引导语时）

引导语是最模板化、跨账号雷同、也最容易被误当「夸大话术」洗坏的一段——**所以不手洗、不逐字改，只在原位置整段替换/插入 Step 1 选定的那条**：

- **删账号自称**：删掉引导语里残留的账号专属自称（「我是XX医生」「我是曹医生」直接删，不回填别的名字）。
- **处理接缝**：把引导语和前面钩子/痛点段、后面干货段的衔接顺通——关联词配对、无半截句、过渡自然、上下文逻辑接得上。检查引导语首句是否与前段末句语义重复（如「…特别管用」接「这个调理方法简单又好用」→「管用」「好用」同义重复，删引导语首句重复部分，直接从下一句开始）。接缝示例见 `style_examples.md` 第 2、8 节。
- **原文无引导语时必须加衔接桥**：引导语库模板是独立成段的（如「下次你就不用专门跑医院来了」），预设了前文已有铺垫。插入陌生上下文时，必须在引导语前加一句桥，把前一段的场景和引导语的承诺连起来（如「这个方子你记好了，下次你就不用专门跑医院来了」← 桥→承诺）。否则症状列举完直接跳到「不用跑医院」，读者不知道「为什么」，逻辑断裂。
- **不造伪因果**：不得把点赞/收藏/关注与疗效或结果（长高、治好）硬绑因果。反例「点个小红心，是为了你家孩子能长高」——荒谬，直接删。
- **主题匹配已在 Step 1 选定**：若落地后通读发现仍不搭，才回 Step 1 从候选里换另一条。

### 收尾节点专项写法

- **收尾不命令**：结尾只给建议、不给操作指令。反例「回去照着做/回去煮上喝/回去照着煮」→ 改为「有时间慢慢看/用的时候翻出来看/记不住先收藏」。收尾模板见 `ending_variants.md`。
- **尾段仅简单收束**：只做一句收藏提醒或简单提问，不堆叠多项互动呼吁。点红心/加号/留言等互动引导属于**引导语段**职能，放尾段会与引导语重复（如「点个小红心让我沾沾福气」这类 → 精简为单句收藏提醒）。
- **不弱化就医、不教唆自疗**（B.① 延伸）：删「小毛病自己就能调」这类引导观众拿偏方替代就医的话；「少往医院跑」属赛道心智钩子可留，但「自己就能调/能治好」这种教唆自我诊疗的必须去。
- **就医提醒求精炼**：医疗高风险的独立就医结尾只保留核心（外敷只是辅助 + 72 小时内就医），不堆叠「是需要正规治疗的/才稳妥/你都记住了」这类冗词。

## 三、今后发现新问题的分流规则（防止「打补丁」惯性）

以前每出一个 bug 就往一张事后清单尾巴加一条，越加越长却防不住新问题。今后**新发现的洗稿问题按性质分流，不再堆清单**：

- **能用正则/关键词判定的** → 加进 `scripts/validate_output.py` 顶部词表（如新出现的禁用词、说死句式）。加规则不动本文件。
- **属写作手法的** → 并入上面 A–F 对应节点，作为写作指令。
- **需人工判断的（语义、逻辑、力度）** → 并入 Step 4 通读关卡。

## 四、硬约束与机器校验

洗稿定稿后、生成 docx 前，**必须**运行机器校验，通过（error 数为 0）再导出：

```bash
python scripts/count_chars.py '脚本正文'
python scripts/validate_output.py '脚本正文' --herbs "荷叶10克,陈皮6克" --syndromes "痰湿内盛"
```

`validate_output.py` 自动查：字数 ≤300、禁用标点（：——""）零命中、单位汉字化、正文无【】、无闲聊腔/市井口气/疗效打包票/账号自称残留、锁死项（`--herbs`/`--syndromes` 传入的克数与证型）全部保全（以上 error 阻断导出）；功效说死/买不到未降档/条件绝对/描述词升级为 warning（易误伤，供人工确认，不阻断）。

硬约束的完整定义（字数上限、标点禁令、单位汉字、绝对不能改）见 SKILL.md「硬约束」节——那是所有步骤共用的编译时规则，本文件不复述。
