# case_02 胆结石 — 期望检查项

## 覆盖场景
- 数字钩子、稀缺话术和有缘人话术需保留力度
- 中医病机归因需严谨，同时给中老年人一句白话解释
- 原文引导语位于钩子后、病机解释前，必须原位替换并做好双接缝
- 方剂药材、克数、病症和证型全部锁定

## 必过检查项

### 语义与口播
- [ ] 情绪安抚使用自然搭配，可用「先别慌」或「不用过度害怕」，不用「先别急着慌」这类近义叠加
- [ ] 安抚情绪不替病情下「没事」「不用治疗」等结论
- [ ] `今天/下面 + 这个 + 内容名词` 有「讲的/要说的/分享的」等所指；直接提醒用「记好」而非「记好了」
- [ ] 不把创作者无法控制的结果说成保证，「不让你多花一分冤枉钱」改成「能让你少花冤枉钱」等帮助表达
- [ ] 医学病因/证型关系不写成唯一必然因果，使用符合范围的「多和/常与/可能与……有关」
- [ ] 「肝胆湿热」保留准确术语，并紧邻一句「湿气、热气」等白话解释
- [ ] 引导语前一句用胆结石、方子或本次方法作主语回指上文，再接比例/稀缺价值判断

### 流量与锁定项
- [ ] 标题「90%的胆结石，记好一个排石方」原样保留
- [ ] `90%` 数字钩子不软化
- [ ] 「挤破脑袋都想学」「有缘人」「医生朋友」等确认过的流量灵魂不降档
- [ ] 海金沙9克、金钱草15克、鸡内金9克原样保留
- [ ] 胆结石、肝胆湿热原样保留
- [ ] 引导语仍在原功能位置，前后两处接缝自然

### 输出
- [ ] 正文 ≤300 字，机器校验 error=0
- [ ] 鉴别诊断、完整适用/禁忌和就医提醒在后三段，不挤正文
- [ ] Word 正文没有批改用【】文本；【】只用于后三段
- [ ] 温馨提示保持两块：适用人群；禁忌人群+注意
